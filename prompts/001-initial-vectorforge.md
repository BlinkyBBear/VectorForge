# Prompt 001 — Initial VectorForge

**Date:** 2026-08-07  
**Goal:** Production raster→SVG tool optimized for laser cutters.

Build a production-ready desktop + web application called "VectorForge" that converts any raster image into clean, high-quality, laser-cutting-ready SVG vector files.

Core requirements included: hybrid vectorization, quality presets, laser-specific tools (units, hairline, kerf, multi-layer export), path editing, DXF/PDF, dark maker UI, offline processing, clean architecture.
